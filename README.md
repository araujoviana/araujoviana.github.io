# Web Portfolio

This is my portfolio website built with Angular and Tailwind CSS, feel free to fork and use it for your own benefit (consult the LICENSE for more details)

## Installation

```bash
git clone https://github.com/araujoviana/araujoviana.github.io
cd araujoviana.github.io
npm install
ng build
```
## Usage

### Development
```bash
ng serve
```

### Deployment
This project comes preconfigured with the Github Pages Angular package by default, but you can [add your own remote server](https://angular.dev/tools/cli/deployment)
```bash
ng deploy
```
